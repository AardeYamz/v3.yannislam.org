# v3.yannislam.org wiki

The source of [yannislam.org](https://yannislam.org): an Angular 22 portfolio site, prerendered to static HTML and served from Vercel. Nearly all page copy lives in one file, `src/assets/config.json`.

These pages summarise the docs kept in the repo ([README](https://github.com/AardeYamz/v3.yannislam.org/blob/main/README.md), [CLAUDE.md](https://github.com/AardeYamz/v3.yannislam.org/blob/main/CLAUDE.md), [docs/](https://github.com/AardeYamz/v3.yannislam.org/blob/main/docs/README.md)). The repo is the source of truth; if a page here disagrees with the code, trust the code.

| Page | What it covers |
|---|---|
| [Getting Started](Getting-Started) | Install, run, build, stack |
| [Architecture](Architecture) | Components, services, routes, theme pipeline, build hooks |
| [Editing Content](Editing-Content) | The `config.json` keys |
| [Testing](Testing) | Vitest, Playwright, Lighthouse CI |
| [CI/CD and Deployment](CI-CD-and-Deployment) | Workflows, Vercel, DNS, dependency security |
| [Conventions](Conventions) | Rules for changing the code |
| [Documentation Guide](Documentation-Guide) | How `docs/` is organised, write-ups by area, reviews |
| [Open Work](Open-Work) | The queue of planned work |
