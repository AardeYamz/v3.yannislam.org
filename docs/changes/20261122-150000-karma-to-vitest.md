# Unit tests: Karma and Jasmine to Vitest

Date: 2026-11-22 15:00:00

Unit tests now run on the Angular `@angular/build:unit-test` builder with
Vitest in Playwright's Chromium, instead of Karma and Jasmine. Karma 6.4.4 was
the last source of the `rimraf@3`, `inflight` and `glob@7` deprecation
warnings (it needs the old rimraf and glob APIs, so overrides break it), and
it carried the minimatch 3 alert that the earlier attempt (#171) targeted.

- Specs converted with `ng generate @schematics/angular:refactor-jasmine-vitest`;
  three mocks that the stricter types rejected were retyped by hand.
- `src/test-setup.ts` restores mocks and real timers after each test, as Jasmine did.
- CI installs Chromium before the unit tests and runs `npm test -- --no-watch --coverage`.
- Dependabot's `testing` group tracks `vitest` and `@vitest/*`.
- `@lhci/cli` still pulls `rimraf@3` through `chrome-launcher`; that part of #236 waits for an upstream release.
