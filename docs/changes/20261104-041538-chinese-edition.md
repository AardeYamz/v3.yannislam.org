# Simplified Chinese Edition (zh.yannislam.org)

The site now has a Simplified Chinese edition, switched with a button at the
top right of the header. It shows the flag of the language it switches to
(China's in English, the US's in Chinese), as inline SVGs.

## What changed

- **`src/assets/config.zh.json`** is a full translation of `config.json`, in
  the same shape. `config.json` gained a `ui` block (button labels, section
  titles, aria-labels, the About paragraphs, the `<title>` and description)
  that used to be hard-coded in templates; `config.zh.json` has its own.
  `config-parity.spec.ts` fails if the two files differ in keys or list
  lengths, or if a link / image / icon differs.
- **`LanguageService`** holds the language as a signal (`en` | `zh`). The
  choice is saved in `localStorage` (`yl-language`). With nothing saved, a
  `zh.*` hostname starts in Chinese and every other host in English. The
  browser's own language is deliberately not used.
- **`SiteConfigService`** now returns the active language's content. Its
  properties became getters that read the language signal, so templates
  re-render on a switch. Components therefore read them through getters
  (header, footer, education, home, projects, projects-highschool) instead of
  copying them into fields once.
- **Hydration:** every route is prerendered in English, so the server and the
  first client render are English; `AppComponent` calls `LanguageService.init()`
  after the first render (the loading screen still covers the page). A Chinese
  visitor therefore receives English HTML first. A second prerender pass per
  language would remove that, at the cost of a second set of routes.
- On a switch `<html lang>` (`zh-Hans`), the title and the description / Open
  Graph / Twitter tags are updated. English keeps the tags authored in
  `index.html`.
- The banner blurb has a minimum height of the English text (7 lines), so the
  name stays at the same height in both languages.
- `TypewriterComponent` restarts when its `strings` change, and erases only back
  to the prefix shared with the next string (“我是一名”, “I am a ”) before typing on.
- The resume button still opens the English PDF; there is no Chinese resume.

## Serving zh.yannislam.org

The code needs nothing more than the hostname: add `zh.yannislam.org` as a
domain on the same Vercel project (and its DNS record), and that host opens in
Chinese. The two hosts do not share `localStorage`, so the button switches the
language in place rather than jumping between hosts.

## Editing

Change copy in both `config.json` and `config.zh.json`. Keep the contact
`name` values (`Email`, `Github`, …) identical: the footer finds the email
entry by name. Keep a space after a URL inside Chinese text, because the
`linkify` pipe reads a URL up to the next whitespace.

## Follow-up: location-based default and disclaimer

- First visit with no saved choice: `detectLanguage()` picks Chinese when the browser's language list has a `zh*` entry or the time zone is in mainland China; otherwise English (so a visitor in the US gets English). No IP lookup or third-party call; the time zone is the location signal.
- The footer carries a disclaimer (`ui.footer.disclaimer`, translated in both configs): the site was written in English and the author is not necessarily fluent in the other languages.

## Follow-up: language menu, flag component, lazy translation

- The header has one flag button (the current language) that opens a menu of the available languages, each with its flag and own name. Flags live in `FlagComponent`; `ui.header.languagePickerLabel` labels the button. This replaces the single toggle so more languages can be added without more buttons.
- `config.zh.json` is a lazy chunk (`config-loader.ts`): only the English config is in the main bundle. `LanguageService.select()` / `init()` are async and wait for the chunk; on a failed download the page stays on the current language.
