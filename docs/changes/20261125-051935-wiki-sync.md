# Publish The Wiki From The Repo

The GitHub wiki was seeded by hand and drifted from `README.md`, `CLAUDE.md` and
`docs/todo/README.md`.

## What changed

- **`wiki/`** holds the nine wiki pages (copied from the wiki as seeded).
- **`.github/workflows/wiki-sync.yml`** clones the wiki repository and mirrors
  `wiki/` into it (`rsync --delete`) on a push to `main` that touches `wiki/`, or by
  hand. It uses the job's `GITHUB_TOKEN` with `contents: write`; no new secret.
- **`CLAUDE.md`** tells contributors to edit `wiki/`, not the wiki, and to update the
  matching page when the source docs change.
- `wiki/Open-Work.md` no longer claims to be a dated snapshot.
