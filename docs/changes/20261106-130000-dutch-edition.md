# Dutch Edition (nl.yannislam.org)

A Dutch edition. Stacked on the Mexican Spanish edition.

## What changed

- **`src/assets/config.nl.json`**: a full translation of `config.json` in the same
  shape (informal "je/ik"). Proper nouns, technology names, institution names and
  links stay as in English. Section anchors are translated (`/#over-mij`,
  `/#opleiding`, `/#ervaring`, `/#vrijwilligerswerk`) and resolve alongside the
  English ids. Machine-written; worth a read by a native speaker.
- **`LanguageService`**: `Language` gains `nl` (`<html lang>` `nl-NL`, name
  "Nederlands"); an `nl.*` hostname pins it. A `nl*` browser language or the
  Europe/Amsterdam time zone defaults to it (Belgium's zone is not used: it is
  not all Dutch-speaking).
- **`config-loader.ts`** gets the lazy import; **`FlagComponent`** gets the Dutch flag.
