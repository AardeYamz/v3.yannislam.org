# Looping YL Mark In The Desktop Banner

On desktop (>=992px) the banner shows one large YL mark alongside the falling
logos. It plays yl-theme's loading-screen animation forever: each piece draws
its outline, fills in, holds, fades and starts again, staggered from the
top-left to the bottom-right.

## Behaviour

- Hovering any piece holds the whole mark solid (out of the loop); no growing.
- The falling logos stay on desktop too, and there they span the whole
  viewport (fixed) so they keep falling behind About and the rest of the page.
- Below 992px nothing changes: the falling logos stay banner-only and the mark
  is not shown.
- `prefers-reduced-motion`: the finished mark is shown static.

## How

- New `components/home/logo-loop`: an inline SVG of the eleven pieces from
  `clearcolor.svg`. The loop is pure CSS (`pathLength="1"` dash for the outline,
  `fill-opacity` for the fill), so it prerenders and hydrates with no JS.
- Both the mark and `app-floating-logos` are in the banner markup and a media
  query decides what shows, so SSR and hydration agree.
- Replaces the closed mosaic approach (PR #72).
