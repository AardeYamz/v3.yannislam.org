# Looping YL Mark In The Desktop Banner

On desktop (>=992px) the banner shows one large YL mark instead of the falling
logos. It plays yl-theme's loading-screen animation forever: each piece draws
its outline, fills in, holds, fades and starts again, staggered from the
top-left to the bottom-right.

## Behaviour

- Hovering a piece fades just that piece into seven smaller logos that scatter
  and fade; the piece fades back in afterwards. Small logos follow the theme
  (colour, black in light, white in dark).
- Below 992px nothing changes: the falling logos stay and the mark is not shown.
- `prefers-reduced-motion`: the finished mark is shown static, hover does nothing.

## How

- New `components/home/logo-loop`: an inline SVG of the eleven pieces from
  `clearcolor.svg`. The loop is pure CSS (`pathLength="1"` dash for the outline,
  `fill-opacity` for the fill), so it prerenders and hydrates with no JS.
- Both the mark and `app-floating-logos` are in the banner markup; a media query
  shows one, so SSR and hydration agree. `display: none` also pauses the
  falling logos' rAF loop through its IntersectionObserver.
- Replaces the closed mosaic approach (PR #72).
