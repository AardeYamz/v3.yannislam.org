# PR Previews Index Is An AG Grid Table

The root page of the previews host now shows every open PR in a sortable, filterable AG Grid table (`ag-grid-community`
36.3.0 from jsDelivr, pinned with an SRI hash) instead of a bare list. Columns: PR number (links to the preview), title
(links to the PR), author, branch, draft, commit and last updated.

`pr-previews-deploy.yml`'s `stage-command` now asks `gh pr list` for the PR details, joins them with the staged previews
and writes `site/prs.json`; `.github/pr-previews/index.html` fetches it. Only `{{THEME}}` is still substituted into the
template. To bump AG Grid, change the version and recompute the `integrity` hash in the template.
