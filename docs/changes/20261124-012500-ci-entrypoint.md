# One CI Entry Point

Part of AardeYamz/workflows#34. `security.yml`, `diagram-lint.yml` and `actionlint.yml` are replaced by one `ci.yml`
that calls the shared `ci.yml` (v1.0.13): diagram lint (mermaid and D2), actionlint, zizmor and dependency review run as
jobs of one run, with one checkout set each. It keeps the Monday 06:30 UTC schedule `security.yml` had.

- `dependency-review` moved out of `build-test.yml` into it. The shared job uses the default severity (`moderate`, was
  `high`); it is not a required check.
- `build-test.yml` stays: the build artifact shared by Lighthouse and e2e, and the Node matrix, do not fit the shared
  workflow's single `test` command.
- CodeQL stays on GitHub's default setup.
- `sync-prs.yml` now dispatches `build-test.yml ci.yml` on a branch it updates (was `build-test.yml security.yml`).
- Required checks (ruleset `main`): `zizmor / Lint workflows (zizmor)` becomes the `ci / ...` zizmor check.
